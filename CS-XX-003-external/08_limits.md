# 验收边界与待办

* 参考后端是稳定的 CPU 模型，验收检查的是实际输出、顺序、模型调用和前缀工作量。此题的结果不能用于推算 GPU 内存、真实语言模型精度或在线吞吐率。
* 正式计数单位为具名测试方法。一个参数行失败，这个方法就失败。方法数、参数行数、192 条输入记录的单个工作负载以及完整模型答卷分别计数。
* 每个非空语义组可以有不止一种合法批次划分。评分比较返回给调用者的内容和从模型端实际观察到的工作。具体缓存数据结构、调度顺序和内部变量名由实现决定。
* 平台供应商编号仍用 XX。采购方冻结样例包的实际导入和同批次的正式框架参数尚待确认。现有程序自检结果不能替代独立模型校准。
