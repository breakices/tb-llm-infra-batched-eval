# 模型校准

4.0.0 尚无在冻结后的题面和起始仓库上完成的模型作答。当前有效样本数为 0/25，整题成功率、Qwen 错误模式复现率和失败签名区分度均待测。

正式试测使用统一 Claude Code 框架，分别对 qwen4-max、kimi-k3.1、glm5.3、opus5.5、gpt6-astra 独立运行五次，保留模型及框架版本、请求配置、完整答卷和逐测试方法的结果。模型运行容器只接收 task instruction 和环境镜像。参考补丁和测试只能在作答结束后从外部挂载。该作者仓库在 GitHub 公开，评测容器还需要限制访问该仓库及其历史版本的网络通路。pytest 参数行和评测器的确定性重放均属于程序测试，不计入 25 份模型答卷。

3.x 的本机试答用于开发合约。该版的仓库、模型入口、评分器及部分题面均与 4.0.0 不同。可复核的旧版案例见 `05_model_failure_evidence.md`。
